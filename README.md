# More Power Systems — Oil & Gas Company Website

A professional, responsive website for **More Power Systems**, built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Setup Instructions

### Prerequisites
- **Node.js** v18+ — [Download](https://nodejs.org/)
- **VS Code** (recommended) — [Download](https://code.visualstudio.com/)

### Recommended VS Code Extensions
- Tailwind CSS IntelliSense
- Prettier – Code Formatter
- ESLint

### Run Locally
```bash
npm install
npm run dev
```
Open `http://localhost:5173` in your browser.

### Alternative: XAMPP (Static Build)
1. Install [XAMPP](https://www.apachefriends.org/)
2. Run `npm run build`
3. Copy `dist/` folder to `C:\xampp\htdocs\more-power-systems\`
4. Start Apache → Open `http://localhost/more-power-systems/`

## 🎨 Design
- **Colors**: Dark Navy, White, Grey, Orange accents
- **Fonts**: Montserrat (headings), Inter (body)
- **Responsive**: Mobile, tablet, desktop
- **Animations**: Fade-in, hover transitions, card lifts
